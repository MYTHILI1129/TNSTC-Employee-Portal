# TNSTC Employee Portal

A Full Stack Java web application designed to simplify employee services for the Tamil Nadu State Transport Corporation (TNSTC).

## Project Overview

The TNSTC Employee Portal provides a centralized platform for employees to access essential services through a web interface.

## Features

- Employee Login
- Employee Dashboard
- Employee Profile
- Salary Slip Management
- Leave Application
- Overtime Management
- Family Pass Requests
- Incident Reporting
- Vehicle Complaint Registration

## Technologies Used

**Frontend**
- React.js
- JavaScript
- HTML
- CSS

**Backend**
- Java
- Spring Boot
- REST APIs

**Database**
- MySQL

**Development Tools**
- Visual Studio Code
- Eclipse IDE
- Git and GitHub

## Application Architecture

React.js Frontend → Spring Boot REST API → MySQL Database

## Project Purpose

The main objective of this project is to digitize employee-related services, simplify request submission, and make employee information easier to manage.

## Future Enhancements

- Role-based authentication
- Employee notifications
- Improved security
- Deployment to a cloud platform
